About Dr. Assistant

Dr. Assistant is an AI-powered medical image analysis system.

This project is an advanced AI-powered system designed to classify pathology images into distinct categories, specifically focusing on colon and lung tissue types. It is built with Flask and TensorFlow and is designed for easy use by students and researchers at Mawlana Bhashani Science and Technology University.

  • Model based prediction system
  • User login before result access
  • Simple and clean medical dashboard experience

Performance Metrics

  • Accuracy: 99.98%
  • Precision: 99.98%
  • Recall: 99.98%
