About Doc. Assistant

Doc. Assistant is an AI-powered medical image analysis assistant.

This project helps classify pathology images into possible categories like colon and lung tissue classes. It is built with Flask and TensorFlow, and designed for easy use by students and researchers.

  • Model based prediction system
  • User login before result access
  • Simple and clean medical dashboard experience
Bringing practical medical AI tools into a clean, accessible interface for students, developers, and clinicians.
